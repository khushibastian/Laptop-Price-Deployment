# Laptop Price Predictor — Streamlit App

Predicts laptop prices using a Gradient Boosting model trained on laptop specs (brand, CPU, RAM, GPU, etc).

## Files
- `app.py` — Streamlit app
- `train_model.py` — trains Linear Regression, Random Forest, Extra Trees, and Gradient Boosting; saves the best model
- `Cleaned_data.csv` — training dataset
- `pipe.pkl` — trained model pipeline (generated by `train_model.py`)
- `df.pkl` — reference dataframe used to populate dropdown options
- `requirements.txt` — Python dependencies

### 5. Get a free ngrok authtoken
Colab has no public port of its own, so `pyngrok` creates a public tunnel to it.
- Sign up free at [ngrok.com](https://ngrok.com)
- Copy your authtoken from [dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)

### 6. Run the app and expose it
```python
from pyngrok import ngrok

ngrok.set_auth_token("YOUR_NGROK_AUTHTOKEN")

get_ipython().system_raw('streamlit run app.py &')
public_url = ngrok.connect(8501)
print(public_url)
```

### 7. Open the app
Click the printed URL (looks like `https://xxxx-xx-xx-xxx-xx.ngrok-free.app`) — this opens the live Streamlit app in your browser.

## Notes
- Colab sessions are temporary — if the runtime disconnects or restarts, repeat steps 2–6.
- Each new Colab session gets a new ngrok URL — share the latest one, not an old link.
- Keep the Colab tab open while others are using the app link; closing it or letting the runtime idle-timeout will kill the tunnel.
